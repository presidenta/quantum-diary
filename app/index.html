Приложение для Android

Установить приложение

Сначала скачается файл — это несколько секунд.

Файл скачан. Осталось его открыть — телефон спросит «Установить?».

Не открылось? Файл лежит в загрузках браузера:

⋮ вверху экрана → «Загрузки» → kvant.apk. Или потяните шторку сверху — там строка о скачанном файле.

Если установка не запускается — откройте страницу в браузере.

Не устанавливается?

«Приложение не установлено»

Старая версия мешает новой. Удалите «Квант» в настройках телефона и откройте файл заново. Записи вернутся после входа.

«Установка заблокирована»

Обычная защита Android. В том же окне нажмите «Настройки» и разрешите установку — спрашивают один раз.

Телефон предлагает проверить файл

Соглашайтесь, приложение проверку проходит. «Неизвестный разработчик» — так помечают любое приложение не из магазина.

Ничего не происходит при нажатии

Страница открыта внутри мессенджера: он не даёт ни скачивать, ни ставить приложения. Нажмите «Открыть в браузере» или скопируйте ссылку и вставьте её в браузер.
