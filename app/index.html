Квант

Приложение для Android

Установить приложение

Скачается файл — пара секунд.
Потом браузер покажет внизу кнопку «Открыть».

Дальше телефон спросит три вещи:
  1. разрешить установку из этого источника — разрешите (спрашивают один раз);
  2. «Установить?» — Установить;
  3. при первом запуске — разрешить уведомления, иначе не будет напоминаний.

Файл скачан.
Нажмите «Открыть» — она внизу экрана.

Кнопка пропала? Потяните шторку сверху — там уведомление о скачанном файле, нажмите его. Или нажмите кнопку ниже: загрузка повторится, и «Открыть» появится снова.

Скачать ещё раз
Дальше телефон спросит:
  1. разрешить установку из этого источника — разрешите;
  2. «Установить?» — Установить;
  3. при первом запуске — разрешить уведомления.
Не устанавливается?

«Приложение не установлено»

Старая версия мешает новой. Удалите «Квант» в настройках телефона и откройте файл заново. Записи вернутся после входа.

«Установка заблокирована»

Обычная защита Android. В том же окне нажмите «Настройки» и разрешите установку — спрашивают один раз.

Телефон предлагает проверить файл

Соглашайтесь, приложение проверку проходит. «Неизвестный разработчик» — так помечают любое приложение не из магазина.

Где лежит скачанный файл

В браузере: ⋮ вверху → «Загрузки» → kvant.apk. Или в приложении «Файлы» → «Загрузки».

Ничего не происходит при нажатии

Страница открыта в окошке мессенджера. Нажмите «Открыть в другом браузере» или скопируйте ссылку и вставьте её в браузер.
