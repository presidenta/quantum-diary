Квант

Приложение для телефона на Android. Напоминания приходят без интернета, даже когда приложение закрыто.

Откройте эту страницу в браузере Сейчас она открыта в окошке мессенджера, а оно не даёт скачивать приложения — кнопка просто не сработает. Подойдёт любой браузер: Chrome, Firefox, Samsung Internet, Opera — какой у вас стоит.

Файл скачан. Приложение ещё не установлено

Значка на телефоне пока нет — и не будет, пока вы не откроете скачанный файл. Android не ставит приложения сам, он всегда сначала спрашивает разрешение.

После установки на телефоне появится вот такой значок с подписью «Квант».

Откройте файл — он называется kvant.apk:

  • потяните шторку сверху вниз — там строка «kvant.apk» или «Загрузка завершена». Нажмите её;
  • или в браузере: кнопка с тремя точками → «Загрузки»;
  • или приложение «Файлы» («Мои файлы») → папка «Загрузки».

Дальше телефон покажет несколько окон подряд и в каждом будет что-то спрашивать. Так и должно быть — это обычная защита Android, а не поломка. Что нажимать в каждом окне, написано ниже, в разделе «Телефон не даёт установить».

Если браузер спрашивает «файл уже скачан, скачать ещё раз?» — значит файл на месте и качать заново не нужно. Нажмите «Отмена» и откройте его из «Загрузок».

Скачать приложение

  1. Нажмите «Скачать приложение» — файл скачается.
  2. Откройте скачанный файл — из шторки уведомлений сверху или из «Загрузок». Без этого приложение не установится и значка не появится.
  3. Телефон спросит разрешение — разрешите и нажмите «Установить». Это нужно один раз.
  4. При первом запуске разрешите уведомления.
Телефон не даёт установить

«Приложение не установлено»

Почти всегда это значит, что старый «Квант» уже стоит на телефоне и мешает новому: поверх старой версии телефон ставить отказывается. Удалите старый и поставьте заново:

Настройки → Приложения → Все приложения → «Квант» → Удалить.

Потом снова откройте kvant.apk из «Загрузок» и нажмите «Установить». Записи не пропадут: если вы входили с паролем, они вернутся после входа.

«Установка заблокирована» или «Неизвестное приложение»

Android не ставит приложения мимо магазина, пока вы сами не разрешите. В этом же окне нажмите «Настройки» (или «Ещё» → «Всё равно установить») и включите разрешение для своего браузера:

Разрешить установку из этого источника — включить.

Спрашивают один раз: дальше телефон будет ставить без вопросов.

«Проверить приложение?» — проверяйте смело

И браузер, и телефон предлагают отправить файл на проверку. Соглашайтесь: приложение проверку проходит. В нём нет ни рекламы, ни слежки, ни скрытых действий — это ваш дневник, который хранит записи на самом телефоне.

Предупреждение «приложение от неизвестного разработчика» проверку не отменяет и вредным файл не называет: так Google и Xiaomi помечают любое приложение не из их магазина, даже совершенно безобидное.

Xiaomi, Redmi, POCO: проверка MIUI

MIUI добавляет свои окна поверх обычных. Они выглядят страшнее, чем есть:

«Отправить на проверку?» → можно соглашаться, можно «Установить без отправки».
«Проверка безопасности» → подождите 10–20 секунд.
«Приложение из непроверенного источника» → «Всё равно установить».

Если MIUI отказывает совсем, выключите на время запрет:

Настройки → Пароли и безопасность → Конфиденциальность → «Установка из неизвестных источников» (или «Проверка угроз») → выключить.

«Небезопасное приложение заблокировано» (Play Защита)

Google предупреждает так про любое приложение не из своего магазина — он просто не знает этого разработчика. Нажмите «Подробнее» → «Всё равно установить».

Ничего не происходит при нажатии на файл

Скорее всего, страница открыта внутри мессенджера. Откройте её в браузере кнопкой наверху — или скопируйте ссылку и вставьте в браузер вручную.
