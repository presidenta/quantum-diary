Квант

Приложение для телефона. Напоминания приходят без интернета, даже когда приложение закрыто.

Откройте эту страницу в Chrome Сейчас она открыта во встроенном браузере мессенджера, а он не даёт устанавливать приложения — кнопка просто не сработает.
Скачать и установить

  1. Нажмите «Скачать и установить» — файл скачается.
  2. Откройте его из уведомления о загрузке.
  3. Android спросит разрешение на установку из этого источника — разрешите. Это нужно один раз.
  4. При первом запуске разрешите уведомления.
