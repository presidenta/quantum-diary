# Вид списка людей (кабинет администратора)

Над списком клиентов два переключателя: **«Списком»** (как раньше, по одному человеку в строку) и **«Плитками»**
(по два в ряд, чтобы на экране помещалось больше людей). Решение владельца 16.11.2026.

Карточка человека одна — её рисует `js/admin.js` (`renderPerson`): фото слева, имя и почта, дата, кнопки
«Квантовый кабинет» и шестерёнка. Модуль только вешает класс `people--tiles` на `#peopleList`, а
`people-view.css` перестраивает те же части в плитку. Выбор запоминается в браузере этого компьютера
(`localStorage`, ключ `admin.peopleView`), без него открывается «Списком».

| Файл | Что внутри |
|---|---|
| `index.js` | `initPeopleView(lang)` — рисует переключатель в `#peopleView`; `syncPeopleView(lang)` — подписи на ru / uk / en |
| `people-view.css` | Переключатель и раскладка плиток |

**Стыковка вне папки:** `admin.html` (стили и `<div id="peopleView">` над `#peopleList`), `js/admin.js`
(`initPeopleView` при старте, `syncPeopleView` в `applyLanguage`), `sw.js` (два файла в `SHELL`).
Убрать — удалить папку и эти строки; карточки останутся списком.
