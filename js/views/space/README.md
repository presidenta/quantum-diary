# Пространство вариантов — вторая вкладка раздела «Квант»

Первая вкладка («Моменты») не изменена: ни её разметка, ни `views/quantum.js`,
ни `core/quantum.js` этим модулем не затрагиваются.

## Из чего состоит

| Файл | Что внутри |
|---|---|
| `index.js` | Единственная точка стыковки: вкладки, монтирование, язык |
| `app.js` | Механика: экраны, таймеры, двери, дневник, хроники |
| `scene.js` | 3D-коридор: двери, космическая пыль, квантовый туннель |
| `template.js` | Разметка раздела |
| `config.js` | Тексты (ru/en/uk), тайминги, лимиты |
| `notifications.js` | Звук, вибрация, системное уведомление, откладывание |
| `../../../css/space.css` | Весь внешний вид |

## Как подключено

Всего четыре строки вне этой папки:

- `index.html` — `<link rel="stylesheet" href="css/space.css">`
- `index.html` — вкладки `#quantumTabs` и контейнеры `#quantumMoments` / `#quantumSpace`
- `js/app.js` — `import { initSpace, syncSpace } from './views/space/index.js';`
- `js/app.js` — `initSpace()` в `boot()` и `syncSpace()` в `render()`

## Что важно знать

**Раздел спит, пока его не открыли.** Ни таймеров, ни анимаций, ни загрузки
three.js, пока пользователь не нажмёт вкладку. При уходе с «Кванта»
`syncSpace()` вызывает `unmountSpace()` — гаснут интервалы, `requestAnimationFrame`,
слушатель `resize` и освобождается WebGL-рендерер.

**Цветов у модуля нет.** `space.css` объявляет только `--qm-*`, и каждая
переменная ссылается на токен Пульта: `--gold`, `--surface`, `--ink`, `--edge`,
`--gold-gradient`, `--sans`, `--serif`. Правка токенов в «Игре мудрецов»
доезжает сюда автоматически. Значения после запятой — запасные, на случай
открытия модуля вне Ежедневника.

**Изоляция.** Все правила CSS начинаются с `.qm-root`. Классы `screen` и
`lang-btn` переименованы в `qm-screen` и `qm-lang-btn` — под этими именами в
`app.css` уже живут чужие правила. Пересечений `id` с `index.html` и
`admin.html` нет (проверено, 44 против 143).

**Режим погружения.** На время 3D-коридора `.qm-root` получает класс
`qm-immersive` и разворачивается на весь экран. Это обязательно: `scene.js`
считает размер рендера и попадание кликов от окна браузера, а не от контейнера.

**Язык** берётся из `state.language`; собственный переключатель в встроенном
режиме скрыт. Подписи вкладок — из словаря `config.js`, общий i18n не расширялся.

> Не добавляйте `transform`, `filter` или `perspective` на `.qm-root` —
> это сломает позиционирование модалки, затемнения и 3D-канваса.

## Хранение

Ключи `localStorage` свои, с данными Ежедневника не пересекаются:
`quantum_lang`, `quantum_doors_texts`, `quantum_akashi_chronicles`,
`last_quantum_jump_time`, `quantum_snooze_count`.

## Известное, не исправленное

В `scene.js` осталось два места — правятся по просьбе, трогать 3D без нужды не стали:

1. `onClick`: условие `e.clientX ? ...` считает клик по самому левому краю
   (координата ровно `0`) касанием и падает.
2. Слушатель `resize` внутри сцены не снимается при размонтировании.
