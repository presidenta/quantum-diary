# Видео дверей

Выкладка 258. Владелец 26.11.2026: «видео сохраняем только на телефоне — на сервер не копируем и между устройствами не
передаём, так проще и реальнее, и можно больше видео»; «и запись экрана тоже»; «человек сохранит на почту с телефона».

## Что видно

- **Настройка Реальностей** («Наблюдатель метавселенной» → «Изменить варианты реальностей»): у каждой двери рядом с
  «Фото» — плашка «Видео» со счётчиком `0/3`. Выбор — галерея, камера, запись экрана (на телефоне это обычный MP4),
  на компьютере — файл. Под строкой — лента кадров с ▶ и «✕», под ней «Видео хранится только на этом устройстве».
- Дверь, в которой есть только видео, — заполненная дверь; без имени она называется «Видео».
- **Открытая дверь** (экран перехода): под снимками — проигрыватель во всю ширину и кнопка
  «Поделиться · сохранить на почту». Это системное окно телефона: почта, облако, мессенджер, «Сохранить видео» —
  файл уходит самим телефоном, мимо нашего сервера. Где окна нет (приложение для компьютера) — «Сохранить файл».
  В приложении для Android встроенный браузер такого окна не умеет — кнопки там нет (для неё нужен новый APK).

## Хранение

- Своя база устройства — IndexedDB `quantum-space-videos`, хранилище `doorVideos`, запись на дверь
  `{ doorId, videos: [{ id, blob, fileName }] }`, до трёх видео (`VIDEO_LIMIT`).
- Файл лежит как есть, без пережатия. Предел — свободная память устройства: не хватило — запись откатывается целиком,
  прежние видео целы, человек видит «На устройстве не хватает места».
- **На сервер не уходит ничего.** Копия фото (`web/js/photo-backup/`) читает только базу фото `quantum-space-photos`.
- Формат, который это устройство не играет (например, HEVC с iPhone в приложении для компьютера), — вместо кадра
  надпись «Это видео не воспроизводится на этом устройстве».

## Как подключено

- `../app.js` — импорт; плашка и лента — `buildDoorMedia`, `refreshVideoStrip`; выбор файла — `onDoorAudioFile`
  (`data-act="video"`); «✕» — `onDoorAudioClick` (`video-remove`); заполненность — `updateDoorStatus`, `saveDoors`;
  имя «Видео» — `refreshDoorMediaFlags`, `doorDisplayName`; открытая дверь — `renderChosenDoorMedia`;
- `../config.js` — подписи `video*`, `doorTitleVideo` на трёх языках;
- `video.css` — подключён в `web/index.html` после `css/space.css`;
- `../../../../sw.js` — оба файла в `SHELL` (работает без сети).

Убрать модуль — удалить папку, импорт и строки выше; база видео на устройствах никому больше не нужна.
