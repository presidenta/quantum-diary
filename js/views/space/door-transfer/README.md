# Перенос дверей файлом

Выкладка 225. Владелец 09.11.2026: «полностью скопировать все файлы, фотографии, аудио из кабинета администратора на
компьютере в кабинет Ладомира на его телефоне».

## Почему файлом

Двери, их записи и фото живут только на устройстве (IndexedDB, localStorage). На сервер записи не уходят вовсе
(предел nginx хоста 1 МБ на запрос, запись в 15 минут — несколько мегабайт), фото — уменьшенной копией
(`js/photo-backup/`), тексты дверей — никак. Поэтому перенос — один файл в полном качестве: выгрузили на одном
устройстве, переслали (Telegram, почта), загрузили на другом.

## Что в файле

`{ format: 'kvant-doors', version: 1, exportedAt, doors: [{ id, text, kind, audio, photos }] }` — сохранённые двери по
порядку, отметка «светлая / страх, обида», запись и до трёх фото в base64. Хроники (история открытий) не
переносятся: это история самого человека.

## Загрузка

- Спрашивает: «Заменить двери на этом устройстве (N) дверями из файла (M)?».
- Двери телефона заменяются дверями из файла; номера дверей — из файла, записи и фото ложатся под ними.
- Прежние тексты, номера и отметки сохраняются в `localStorage['quantum_doors_before_import']`; их записи и фото
  не стираются — прежние двери можно вернуть.
- Фото из файла копия на сервере (`photo-backup`) отправит в аккаунт вошедшего при следующей сверке.

## Где кнопки

Под «Отмена» на экране настройки дверей: «Выгрузить двери в файл», «Загрузить двери из файла». В приложении для
телефона «Выгрузить» скрыта: WebView Capacitor не умеет скачивать файл со страницы. Загрузка работает везде.
