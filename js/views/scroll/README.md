# Свиток «Мудрость дня»

Свиток на главной («Квант», пустой пульт), сразу под «Арканом дня». Раз в
сутки, ровно в 00:00 по местному времени, человеку выпадает одно послание из
базы; весь день до 23:59 оно одно и то же.

## Из чего состоит

| Файл | Что внутри |
|---|---|
| `index.js` | Единственная точка стыковки: отрисовка, анимация, полночь, память «открыт сегодня» |
| `engine.js` | Чистая логика без страницы: хеш, выбор послания, дата дня, приведение базы |
| `texts.js` | Подписи на ru / uk / en: заголовок, «Свернуть», сноска о повторе |
| `predictions.json` | База посланий |
| `scroll.css` | Весь внешний вид: пергамент, валики, лента с бантиком, шаги анимации |

## Как подключено

Всего пять строк вне этой папки:

- `index.html` — `<link rel="stylesheet" href="js/views/scroll/scroll.css">`
- `index.html` — место `<div id="dailyScroll"></div>` сразу после `#quantumArcana`.
  **Сменить место на экране — перенести эту строку.**
- `js/app.js` — `import { initScroll, syncScroll } from './views/scroll/index.js';`
- `js/app.js` — `initScroll()` в `boot()` и `syncScroll()` в `render()`
- `sw.js` — файлы папки в списке `SHELL`, чтобы свиток открывался без сети

Убрать модуль целиком — удалить папку и эти строки.

## Выбор послания

`номер = hash(userId + "|" + дата) % число_посланий` (`engine.js → pickIndex`).

- Повторы не исключаются: каждый день выбор из всей базы заново. Совпало со
  вчерашним — так задумано, об этом сноска под текстом.
- Число посланий берётся из самой базы, в коде его нет.
- Без входа в аккаунт `userId` пустой — послание у всех таких людей одно на день.

## Как заменить базу

`predictions.json` — массив `{ "ru": "…", "uk": "…", "en": "…" }`. Украинский
можно назвать и `ua`, допускается и обёртка `{ "predictions": [ … ] }` —
`normalize()` приведёт к одному виду. Положить файл на место, поднять номер
выкладки — и всё. Тест `test/svitok-dnya.test.js` проверит, что у каждого
послания есть все три языка.

## Состояние

`getMeta('dailyScroll') = { date, open }`. Открыли сегодня — при входе свиток
уже развёрнут, под ним кнопка «Свернуть». Наступил новый день — свиток снова
завязан ленточкой.

## Анимация

Классы на `.ds` по очереди: `ds-untie` (лента развязывается, 450 мс) →
`ds-turn` (поворот из диагонали в горизонталь, 650) → `ds-wide` (вытягивается
во всю ширину, 500) → `ds-unroll` (бумага разматывается, 850) → `ds-open`.
Длительности стоят парой в `STEPS` (`index.js`) и в переходах `scroll.css`.
Свернуть — те же шаги в обратном порядке. При «уменьшить движение» в системе
свиток открывается сразу.
