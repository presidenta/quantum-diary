# Нет связи — своя страница APK

Выкладка 218. Владелец 07.11.2026: «чтобы приложение работало без интернета».

## Зачем

Приложение открывает сайт (`server.url` в `capacitor.config.json`). Без сети его страницу отдаёт запас
служебного работника (`web/sw.js`, выкладки 213 и 216). Запаса нет в двух случаях: самое первое открытие
после установки и стёртые данные приложения. Тогда на экране была системная страница
`ERR_INTERNET_DISCONNECTED`, а от неё назад в приложение не вернуться.

Теперь Capacitor в этих случаях показывает `index.html` из этой папки (`server.errorPath`). Страница говорит,
что случилось. Как только сайт отвечает, она сама открывает приложение: проверка каждые 5 секунд, при
появлении сети и при возвращении на экран, а также кнопкой «Попробовать снова».

## Почему всё в одном файле

Мост Capacitor (`WebViewLocalServer.isErrorUrl`) отдаёт с телефона ровно адрес
`https://localhost/no-network/index.html` и ничего рядом. Отдельные стили или скрипт не загрузились бы.

## Чего она не даёт

Это не второе приложение без сети: на `localhost` нет данных человека, они лежат у сайта. Поэтому страница
только ждёт связь и возвращает человека в настоящий «Квант». После первого открытия с сетью запас уже
собран, и дальше приложение работает без интернета, а эта страница больше не показывается.

## Как подключено

- `capacitor.config.json` — `"server.errorPath": "no-network/index.html"`. Это нативная настройка, она
  доезжает до телефона только с новым APK (сборка идёт сама на правку этого файла).
- Адрес сайта в странице совпадает с `server.url` — замок в `test/bez-seti-pervoe-otkrytie.test.js`.
- Связь проверяется по `version.json`: GitHub Pages отдаёт его с `Access-Control-Allow-Origin: *`. Если
  сайт переедет туда, где этого заголовка нет, страница будет ждать вечно. Тогда заголовок нужно добавить там.
- В `SHELL` служебного работника страница не входит: её отдаёт сам APK, а не сайт.
