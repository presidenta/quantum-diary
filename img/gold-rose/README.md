# Образцы золота — розовое

Снимки металла, которые «вырезаются и вставляются» в кнопки и буквы: картинка ставится фоном и обрезается по
кнопке или по контуру букв (`background-clip: text`) — так золото выглядит настоящим, а не нарисованным.

| Файлы | Что это | Где стоит |
|---|---|---|
| `../gold/n01.jpg` … `n12.jpg`, `sv-*.jpg` | Жёлтое золото «Кванта» (соседняя папка `img/gold/`) | `css/app.css`: `--gold-gradient`, кнопки времени, пульт |
| `rose-sample.jpg` | **Розовое золото** — образец владельца целиком (12.11.2026): жидкий металл в рамках | Образец, на сайте не подключён |
| `rose-01.jpg` | Розовое золото: середина большой пластины без рамки | GSL Woman+ — все золотые кнопки, пластины и буквы (`styles/tokens.css` → `--g-rose-img`) |
| `rose-02.jpg` | Розовое золото: длинная нижняя пластина | Запас для широких полос |

Новый образец — сюда же, с короткой строкой в этой таблице.

**Почему розовое лежит отдельно от `img/gold/`.** Всё из `img/gold/` «Квант» скачивает каждому человеку при установке
для работы без интернета (`web/sw.js` → SHELL; замок `test/oflayn-prilozheniya.test.js`). Розовое золото сайт
«Кванта» не использует, поэтому оно здесь, рядом, и в установку не попадает. Понадобится на сайте — перенести файл
в `img/gold/` и добавить его в SHELL.
